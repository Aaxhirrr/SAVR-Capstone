### 1. AuthField
* **Swift**: `AuthField.swift`
* **React Native**: `auth-field.tsx`
* **Description**: A form input component designed for authentication. It supports both standard text (like email/username) and secure text entry (passwords). It includes a title label positioned above a styled text input with a continuous border.

### 2. CheckboxToggleStyle
* **Swift**: `CheckboxToggleStyle.swift`
* **React Native**: `checkbox-toggle-style.tsx`
* **Description**: A custom interactive checkbox component. It replaces the default iOS toggle switch with a square checkbox that displays a green background and a checkmark (`✓`) when active, accompanied by a text label.

### 3. FeatureCard
* **Swift**: `FeatureCard.swift`
* **React Native**: `feature-card.tsx`
* **Description**: A tall, content-rich card used to highlight app features. It contains a rounded icon container at the top, a bold title, and a descriptive body paragraph, all wrapped in a white card with a subtle border.

### 4. FooterView
* **Swift**: `FooterView.swift`
* **React Native**: `footer-view.tsx`
* **Description**: The standard application footer. It includes a top divider line, the SAVR logo (with its signature red dot), copyright/location text, and a horizontal row of links (Blog, Privacy, Terms).

### 5. HeroSearchBar
* **Swift**: `HeroSearchBar.swift`
* **React Native**: `hero-search-bar.tsx`
* **Description**: A prominent, visually distinct search bar designed for the top of the screen (hero section). It features a beige camera button on the left, an input area in the center, and a green submit arrow on the right, all outlined by a thick orange border.

### 6. InfoCard
* **Swift**: `InfoCard.swift`
* **React Native**: `info-card.tsx`
* **Description**: A compact display card with a top-aligned icon, a bold title, and a shorter subtitle. It uses a light gray background and a soft drop shadow (`boxShadow` in React Native) to lift it off the page.

### 7. MetricsBar
* **Swift**: `MetricsBar.swift`
* **React Native**: `metrics-bar.tsx`
* **Description**: A dark green, pill-shaped container that displays a 2x2 grid of key metrics. Each metric includes a large numeric value, a bold label, and an optional sub-label, separated by thin, semi-transparent divider lines.

### 8. PillTag
* **Swift**: `PillTag.swift`
* **React Native**: `pill-tag.tsx`
* **Description**: A small, capsule-shaped tag that automatically uppercases its text. It features a translucent white background and a thin gray border, typically used for highlighting categories like "NEW" or "DEALS".

### 9. ProcessCard
* **Swift**: `ProcessCard.swift`
* **React Native**: `process-card.tsx`
* **Description**: A specialized card used to explain a multi-step process. It features a large, faint background number at the top right, a centered icon, a step indicator (e.g., "Step One"), a title, and descriptive body text.

### 10. SavrLogoView
* **Swift**: `SavrLogoView.swift`
* **React Native**: `savr-logo-view.tsx`
* **Description**: The core brand asset component. It renders the lowercase "savr" text in a heavy, rounded font with a signature red dot offset slightly to the top-right of the "r". It accepts dynamic font sizes.

### 11. SavrNavBar
* **Swift**: `SavrNavBar.swift`
* **React Native**: `savr-navbar.tsx`
* **Description**: A standard top navigation bar. It aligns the SAVR logo on the left and provides two pill-shaped call-to-action buttons on the right: a secondary "Sign In" button and a primary "Get Started" button.

### 12. SavrSearchBar
* **Swift**: `SavrSearchBar.swift`
* **React Native**: `savr-search-bar.tsx`
* **Description**: The standard inline search input. It includes a placeholder ("What are you shopping for?"), a camera icon for photo search, and a submit button. It has a white background with a subtle drop shadow.

### 13. SavrTopBar
* **Swift**: `SavrTopBar.swift`
* **React Native**: `savr-top-bar.tsx`
* **Description**: An expanded, larger header component used on prominent screens. It features the SAVR logo, a "Live prices updating" indicator with a green pulsing dot, and two full-width capsule buttons ("Sign In" and "Get Started") stacked below.

### 14. StatBar
* **Swift**: `StatBar.swift`
* **React Native**: `stat-bar.tsx`
* **Description**: A dark green vertical container that lists major statistics. It iterates through an array of tuples (Value, Label), stacking them vertically and separating them with thin, semi-transparent horizontal dividers.

### 15. StoreChip
* **Swift**: `StoreChip.swift`
* **React Native**: `store-chip.tsx`
* **Description**: A simple, pill-shaped chip component used to denote store names (e.g., "Walmart", "Costco"). It features a white background, bold dark green text, and a solid gray border.
